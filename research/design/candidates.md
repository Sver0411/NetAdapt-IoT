# 研究方向比较

围绕多业务共享资源，比较以下三个技术方向。

| 项目 | A：共享出口时效与公平调度 | B：应用感知 MPQUIC 路径选择 | C：混合 IoT 准入与整形 |
|---|---|---|---|
| 研究问题 | 状态流与截止期流如何分配服务机会 | 异构路径如何匹配应用需求 | 过载时如何接纳并服务业务流 |
| 方法 | AoI 降幅、紧迫度、服务欠账 | 预计完成时间与路径选择 | 负载估计、token bucket、流级接纳 |
| 相关文献 | P01–P04、R03–R06、R12–R14 | P04–P09 | P01–P03、R06–R11 |
| 基线 | FIFO、RR、WRR、EDF、Priority、MaxWeight、PF、AoI-gain、Debt | minRTT、RR、ECF、BLEST | 静态配额、需求感知接纳、EDF、DRR |
| 指标 | AoI、事件 miss、PDR、公平性、吞吐 | 完成时间、尾延迟、及时率、乱序 | 接纳率、miss、估计误差、队列 |
| 实验平台 | Python 与双端 ESP32/E220 | Linux 或 ns-3、多条独立路径 | Python、业务请求接口与反馈 |
| 实现重点 | 统一队列与配对机制比较 | 传输栈、拥塞窗口与重排 | 容量估计与需求建模 |

选择 A 作为当前主线：共享出口提供清晰的资源约束，便于组合机制分析、基线比较和现有设备重放。B 与 C 分别作为传输层扩展和流级资源管理方向。

项目题名：面向混合物联网业务的共享网关出口调度——信息时效、截止期与公平性的实验研究。
